# 第一版验收记录

验收日期：2026-09-14。环境：Windows、Node.js 24.15.0、LibreOffice 26.2.6.3、SQLite。本记录仅覆盖单商家、单设备的测试支付 / PDF 文件输出版本。

## 自动化结果

`npm test`：16 项通过，0 失败，约 28 秒。使用隔离的 `test-results/api-*` 数据目录。

- 未登录后台访问、跨站写入和跨顾客文件访问均被拒绝。
- 真实 PDF 页数与横竖页面标准化；真实 DOCX / DOC 转换，中文表格和图片可读；照片 EXIF 旋转正确。
- 加密、损坏、伪装和超限文件被明确拒绝；订单 100 MB、2000 正文面限制生效。
- 服务端报价、价格快照、重复下单及重复模拟支付的幂等处理正确。
- 双面三页两份生成 10 页：封页及其空白背面、两份正文与各自末尾空白。金额只计算 6 个正文面。
- 多文件单面输出、失败重试、暂停接单、取消未支付订单、队列恢复通过。
- 商家概览、订单搜索、设置保存、密码修改后其他后台会话失效通过。
- 过期文件实际删除，下载与重试被拒绝，订单摘要保留。

`npm run build`：TypeScript 检查及 Vite 构建通过。当前 PDF 预览相关主包约 746 KB（gzip 228 KB），存在体积提示，不影响构建。

`npm run check`：字体、Word 转换器、初始化密码及 mock 模式已配置。

`npm run backup`：使用隔离验收目录验证 SQLite 和文件备份成功。

## 浏览器实际操作

1. 顾客上传三页 PDF 和两页 Word，逐页查看预览，设置双面、两份、称呼「验收同学」。
2. 服务端报价 2.00 元，创建订单并模拟支付。页面明确显示不会扣款。
3. 取件码 `166145` 的订单生成 14 页待打印 PDF，浏览器捕获下载事件。
4. 商家后台概览显示一笔订单、测试金额 2.00 元；按取件码搜索并打开详情，核对称呼、金额、文件清单、输出页数及处理记录。
5. 后台价格保存出现成功反馈；检查封页、基础设置、设备管理和入口二维码。
6. 在 390 px 视口检查后台布局与菜单导航，页面无横向溢出；顾客端已检查手机布局、文件预览及完整下单流程。
7. 服务重启后原订单与后台登录会话仍可读取。构建后的静态页面由 API 服务直接提供。
8. 使用 `npm run lan` 后，本机通过局域网地址读取接口成功；后台二维码内容显示 `http://192.168.43.180:8787`。尚未使用真实手机扫码验证，防火墙和 Wi-Fi 隔离需要在现场确认。
